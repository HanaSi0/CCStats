# CCStats

FF14 水晶冲突战绩插件。支持战绩查询、数据分析、地图回放和国际服榜单。

在 Dalamud 自定义插件库中添加：

```text
https://raw.githubusercontent.com/HanaSi0/CCStats/main/repo.json
```

搜索 **CCStats** 安装，输入 `/ccstats` 打开。

版本：**0.2.12** · 国际服 Dalamud API 15。原 `repo-test.json` 库链仍可使用。

[更新说明](docs/release-notes/0.2.12.md) · [开发文档](docs/development.md)

基于 SaMo 的 [PvPStats](https://github.com/wrath16/PvpStats)，遵循 [MIT 许可](LICENSE.txt)。
