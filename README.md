# CCStats 1.0.4

**让每一场水晶冲突，都有迹可循。**

CCStats 正式发布。由 **HanaSi0** 开发与维护，将对局数据记录、战绩分析与 **3D 实时渲染回放** 集于一个游戏内窗口。

## 从战绩，到赛场

- **记录每一局**：胜负、段位、造成伤害、受到伤害、治疗量与推车时间，支持筛选与历史战绩查询。
- **走进 3D 回放**：精简地图、鲜亮红蓝棋子、单字职业简称与朝向；通过时间轴、逐帧、变速和自由视角查看对局。
- **看清关键时刻**：双方血量与状态、水晶位置和行进轨迹、二维推进进度，以及已记录的 LB 和地图事件。
- **发现自己的表现**：职业与玩家分析、地图胜率、个人纪录，以及按需计算的高级数据。
- **随时查看榜单**：国际服官方榜单、大区切换、本机角色高亮与快速定位。
- **按习惯使用**：中文界面、自定义配色、悬浮入口与旧 PvP Tracker 数据导入。

## 安装

在国际服 Dalamud 的自定义插件库中添加：

```text
https://raw.githubusercontent.com/HanaSi0/CCStats/main/repo.json
```

搜索 **CCStats** 安装，输入 `/ccstats` 打开。支持 Dalamud API 15。已使用 `repo-test.json` 的用户无需换库，两个入口均提供正式版。
