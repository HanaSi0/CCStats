# 1.1.0 功能与清理检查

日期：2026-10-18。此记录区分自动化验证、源码检查和仍需游戏宿主的项目。

## 仓库清理

删除主分支中 1.0.0–1.0.8 的旧安装包/校验文件、初期 UI 网页和样图、空维护指南、过期地图采样说明，共 32 个文件、189,436,699 字节（约 181 MiB）。重写当前开发文档和迁移入口，移除旧版本、检查数量、窗口操作及暂停状态的误导说明。

保留 1.0.9 过渡包，避免当前库链在新版本发布前失效；1.1.0 包另行加入。旧 Release、标签与 Git 历史保留，不重写历史，故已有克隆的 .git 不会因此缩小。用户本机数据不受影响。原始译文/参考快照、官方地图原图与研究证据保留；旧版本说明只作为历史。

## 修复

- `/lastmatch` 与 IPC 详情入口把窗口操作交给 UI 绘制队列，不从后台直接创建或激活窗口。
- 缓存向读者返回稳定列表快照，更新前物化延迟查询；先持久化再发布新增/替换列表，避免列表并发枚举异常及保存失败时提前发布新条目。快照隔离列表结构，不深拷贝每个比赛对象。
- 历史校验改用独立修订号，避免 CCStats 1.x 被上游 2.x 比较规则判为“永远过旧”；全部修复成功后才记录完成，新导入重置修订。
- 登录延迟刷新可在卸载时取消，观察并记录异步异常；采集初始化全部成功后才订阅框架事件，部分初始化失败时清理已建 Hook。
- 补全设置与最近比赛命令说明的中文。网络诊断命令记录四区结果后再报告失败。
