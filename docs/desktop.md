# CCStats Desktop 内部迭代

本轮仅移植、修改和内部验证，不创建新的发行标签或发布 EXE。

## 桌面工作台

独立 Windows 应用，自动识别游戏进程，提供战绩查询、筛选、收藏/标签、CSV/JSON 导出、结算详情、地图/职业/玩家分析、个人纪录、个人资料、段位趋势、四区官方榜单、时间线、技能分析、按需高级推算和 2D/3D 回放。

历史数据库以只读连接读取。自有资料库单独保存在 `%LOCALAPPDATA%\CCStatsDesktop`；相同记录去重，重新读取保留用户自己的收藏与标签。回放与分析按需加载，位置数据使用现有压缩格式保存，结算未知值显示为 —。

3D 使用后台构建的冻结模型、单色调色板纹理、限定动态顶点预算；地图、棋子、朝向、防御球、极限技、召唤物和场地机制复用现有规则。范围裁剪、动态状态、旧记录缺失数据等边界继续保留，不伪造位置或判定。性能须以实际 Windows 游戏环境验证，不能把离线检查当成实机帧率。

## 自动识别与后台运行

启动后每 2 秒查找游戏，优先前台客户端。匹配地址后连接，进入水晶冲突时可自动记录。异常会延迟重试，切图会收尾上一段。设置可关闭自动识别或自动记录。

点击关闭时，选择“立即退出”或“最小化到托盘”，可勾选“记住我的选择”；在设置中随时恢复询问或更改。托盘状态保留采集与写盘；托盘图标可恢复窗口或退出。真正退出先停止采样、完成当前记录，再释放数据库。

## 数据边界

独立只读采集已接入已加载玩家的位置、朝向、体力、职业、服务器名称与状态，以及经过类型/范围检查的队伍、推进、水晶对象、LB 召唤物、场地施法、场景资源状态和保留的动作效果槽。个人资料另外读取客户端累计场次、胜场与段位，不由本机观测次数代替。公开布局仍需真实客户端验证；已有记录可展示的字段不等于当前采集器能够完整获取这些字段。不能用血量差替代伤害来源，不能把观测片段算作有效胜率样本。

动态冲刺带边界和书库供给/桥梁状态等既有未映射内容仍是已知差异。需要客户端观测后继续适配。

## 完整适配进度（2026-10-19）

本轮补齐了持久状态与动作效果槽的独立读取、去重、召唤物归属、回放保存、数据库/JSON 往返、推进数字、个人资料缓存和观察来源说明。所有读取只请求进程查询与读取权限；没有向游戏进程写入或加载代码。

采集页新增“导出采集诊断”。读到可见的 PvP 结算界面时，保存有类型、索引的有限基本字段到 observations/diagnostics；只采集结算界面，不转储任意内存。最多保留 64 份，导出 ZIP 总计上限 32 MiB。它用于核对当前版本的结算字段，尚不把未知索引解释成伤害或胜负。诊断写盘失败不会终止位置记录。
