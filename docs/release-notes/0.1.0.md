# CCStats 0.1.0

首个供游戏内测试的版本，基于 SaMo 的 PvpStats（MIT）。

- 仅保留水晶冲突；中文名词与界面，打开指令 `/ccstats`。
- 圆角主窗口、侧栏、战绩查询与筛选、自定义主题。
- 用户提供的 Logo；悬浮入口左键打开、右键拖动并保存位置。
- 每局完整结算：造成伤害、受到伤害、治疗量、推车时间等；胜率图表附百分比和实际样本数。
- 日服、北美服、欧服、大洋洲服官方榜单；启动时按官网日期检查缓存。

插件库链接：
```text
https://raw.githubusercontent.com/HanaSi0/CCStats/main/repo.json
```
添加至 Dalamud 设置 → 实验性 → 自定义插件库，保存并刷新安装器，搜索 CCStats。

要求 Dalamud API 15。若安装过上游 PvP Tracker，请先停用；内部名称沿用 PvpStats，以兼容既有记录。替换前可备份配置目录。

本地已通过 Release/Debug 构建和 142 项回归检查。实际比赛采集、Hook 签名与目标客户端兼容性仍需游戏内测试。
