# CCStats 1.0.4

七张 3D 回放地图复查与核心地形优化。

- 赤土红沙恢复被高度和地面包络裁剪误删的峡谷岩壁、坡面、边缘和连接结构，不将雾效平面补成地面。
- 海岸斗场补回核心平台之间的原生地面与完整场地标识，保留原有精简平台，继续剔除外围建筑和散落装饰。
- 角力学校、火山之心、九霄云上、机关大殿和休兵书库保留现有核心布局，清理重复面、重复顶点和冗余共面细分。
- 地面、坡道、通道、主要掩体和高差优先保留。无法验证的自动简化结果回退到原始拓扑，不通过硬裁剪追求更低面数。

七图总顶点数由 2,485,685 降至 2,210,359，减少约 11%；压缩资源从 19,340,744 字节降至 19,050,346 字节。恢复缺失地形后总面数为 1,506,012，约为用户原始导出面数的 34%。这些是模型统计，不代表已测得游戏内帧率提升。

验证包括七张最终 CCM 资源的浏览器渲染、旋转、重置与俯视；最终网格优化在 0.25 单位采样间距下没有减少地面/坡面投影覆盖。插件还执行地图解码、关键恢复地形和构建检查。显示模型不等于游戏导航或碰撞网格。
