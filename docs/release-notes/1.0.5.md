# CCStats 1.0.5

修复赤土红沙两侧圆形区域空洞，重新绘制回放地图机制。

- 原始地图导出也缺少两处近地面圆形地板。本版沿原有边界、相邻高度和颜色补建显示地板，不作为游戏碰撞数据。0.2 米采样复查，原先缺失的 64,528 个点全部覆盖。
- 恢复原生雾层和流沙视觉层，使用透明绘制；透明层不再参与地面高度估算，避免棋子落到雾层或被实心灰板遮挡。
- 二维、三维地图都去掉重叠的机制名称、倒计时和通用三角标记。机制名称仅在展开事件记录后显示，并通过动作 ID 识别已有记录。
- 对照官网行为和客户端 Action 表接入 13 个机制动作。伤害橙红、分摊金色、护盾青色、恢复绿色、击退紫色、视线粉色；吸引向内收缩、击退向外扩散。
- 使用真实读条、结算动作、来源和落点绘制。治疗针刺按分摊护盾处理；阴阳术显示视线轮廓而非全员命中圈；自爆十字、机关地板分别绘制。新版额外记录地面读条的目标位置。
- 纯计时器、未知动作或缺失落点不生成假范围；旧战绩仅使用实际保存的观测。机制显示独立于 LB 开关。

范围尺寸是客户端数据支持的复盘参考，不等于完整碰撞判定。十字布局及具体命中边界尚未逐条游戏内实测；无实际记录的固定机关和魔力桥状态不会凭周期补造。

已执行纯逻辑检查、Release/Debug 构建、资源解码和地图浏览器渲染检查；云环境无法验证游戏内 Direct3D 的实际显示。
