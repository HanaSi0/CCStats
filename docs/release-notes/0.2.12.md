# CCStats 0.2.12

比赛详情 → 细项分析与回放 → **3D 回放（试验）**。原二维回放也提供入口。

- 内置七张精简地图，按需加载；带深度缓冲的 Direct3D 11 离屏渲染，更新目标 30 帧/秒。
- 直接读取现有目标 30 次/秒的走位记录，棋子保留职业和朝向；两侧显示双方成员、血量及状态剩余时间，上方控制时间轴和倍速。
- 显示已观测的水晶位置、轨迹、地图事件与减员；大菱形代表水晶。底部参考圈默认半径 5 游戏单位，可调整，尚未确认为服务端实际判定半径。
- 不跨缺帧、减员或传送跳点插值；不提前显示下一采样的血量或状态。旧记录缺少高度时显示地形估计提示，长局降采样记录保留真实密度。
- 左键旋转、右键平移、滚轮缩放；可跟随选中的玩家。三维窗口单独保存尺寸。

云环境可验证构建、地图资源、数据兼容和插值逻辑；实际游戏内的 Direct3D 渲染、交互与性能需本次测试验证。
