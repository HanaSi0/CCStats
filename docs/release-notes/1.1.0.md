# CCStats 1.1.0

维护与稳定性更新，清理旧文件并修复战绩读取和窗口入口。

- 清理主分支旧安装包、早期 UI 样图及过期说明，移除约 181 MiB 冗余文件；保留上一版过渡包、历史 Release、官方地图与译文资料。
- 修复最近比赛命令及 IPC 入口从后台操作窗口的问题。
- 隔离战绩缓存列表，避免边读取边替换时发生枚举异常；保存后再发布列表更新。
- 历史数据修复使用独立修订号，避免每次启动反复运行，新导入仍会校验。
- 完善登录延迟刷新取消和采集 Hook 部分初始化失败时的清理；补全命令说明中文。

验证：686 项离线检查、Release/Debug 构建、416 项 UI 文本审计及 24 种机制样式的浏览器 WebGL 绘制通过。北美 300 条、大洋洲 100 条官网抓取及再次启动的同日缓存复用通过；日服、欧服联网验证受云环境代理 403 限制。

本环境未运行游戏宿主，实际采集签名、点击交互、Direct3D 与帧率仍需游戏内测试。准确加速带及书库动态状态仍待接入。详情见 [验证记录](../release-validation-1.1.0.md)。

原库链继续使用，在卫月检查更新即可；不会删除用户本机战绩或设置。
