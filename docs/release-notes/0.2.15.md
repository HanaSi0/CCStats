# CCStats 0.2.15

3D 回放加入全部 21 个职业的 LB 和主要专属后续技能范围，可通过「极限技范围」开关显示。

- 增益与治疗使用浅蓝色，伤害与控制使用浅红色；单体技能仅画目标标记／连线，自身效果使用小圈。
- 即时效果在实际效果包到达时提示，约 0.65 秒内淡出。单体施放阶段可显示有时限的瞄准连线。
- 持续效果在初始提示后变淡，实际底色不透明度约 4%。移动光环跟随施法者，固定地面区域留在施放位置；有状态观测的效果随状态结束，不假定始终持续到说明中的上限。
- 白魔长条、暗黑双向长条、战士扇形、机工单体连线、龙骑落地外圈与内圈、召唤物效果、贤者区域及南十字复合范围分别处理。贤者移动区域不重置原有 15 秒时限。
- 记录新的实际施法位置、朝向、地面落点、目标位置、来源及状态关联。召唤物使用其自身位置。仅对已观测动作绘图，规则不会生成未发生的技能。
- 玩家朝向改为更长的浅金色箭头，增加深色背衬与箭杆，独立于队伍色。

范围依据官网 PvP 指南、客户端动作表和用户提供的八职业狼狱采集。未公开的扇形角度、南十字宽度及黄昏前后长度分配为参考形状，提示在范围开关上。显示区域是复盘辅助，不是服务器命中判定证明；单体连线不表示沿线所有玩家均会受伤。历史版本技能可能与当前说明不同。

旧战绩仅在有邻近过去位置采样时估计施法姿态；缺少实际地面落点、目标中心或召唤物位置时跳过相应形状。旧数据无法补回当时未记录的信息。持续效果状态不足时可只显示初始效果或不显示。

保留狼狱采集测试入口，但不要求逐个职业等待 LB。已分析上传的八职业批量记录，汇总不包含玩家姓名或实体 ID。
