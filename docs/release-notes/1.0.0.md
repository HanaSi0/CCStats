# CCStats 1.0.0 正式发布

让每一场水晶冲突，都有迹可循。

**CCStats** 是由 **HanaSi0** 开发与维护的水晶冲突数据记录插件，支持 **3D 实时渲染回放**，将战绩查询、数据分析与地图复盘整合进游戏。

- 记录胜负、段位、伤害、承伤、治疗与推车时间，支持历史战绩筛选。
- 3D 地图回放支持时间轴、逐帧、变速、玩家跟随和自由视角，展示红蓝双方走位、职业与朝向。
- 展示双方血量与状态、水晶轨迹、推进进度、已记录的 LB 和地图事件。
- 提供职业与玩家分析、地图胜率、个人纪录与按需计算的高级数据。
- 支持国际服官方榜单、角色高亮、自定义色彩主题、悬浮入口及旧 PvP Tracker 数据导入。

输入 `/ccstats` 打开。现有正式库与测试库均可直接更新到 1.0.0。

回放依赖客户端实际采集的数据，旧记录缺失的信息无法补回；部分范围仍为参考展示，高级减伤等数据为估算。本次发布通过云端编译和自动检查，游戏内 GPU 渲染仍以实际运行结果为准。
