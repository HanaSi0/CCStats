# CCStats 1.0.3

重写 LB 召唤物采集与 3D 显示，修复上一版过于严格的对象筛选导致完全不显示的问题。

- 召唤技能包在主人解析与统计处理之前独立记录，不再因 NPC 无主人信息而直接丢失。
- 对象识别增加召唤物自主技能来源的实体 ID，不再仅依赖两个固定 NPC 名称 ID；对象采样从玩家走位采样中独立。
- 有实际对象采样时优先使用观测；没有可识别对象但存在已记录的 LB 落点时，显示空中占位符与 30 码持续索敌波纹，持续时间按官方 20 秒估计。无法确认落点时不拿施法者位置替代。
- 记录到对象确实消失后停止显示；同一召唤的使用与命中包不会反复延长估计持续时间。
- 连线改用真正的三维光束，修复召唤物正下方目标因水平距离为零而不显示连线的问题。
- 波纹沿地图表面绘制，加宽并提高可见度；占位符放大，实际攻击与治疗连线保留紫色和薄荷绿，延长至 1.2 秒后淡出。
- 旧战绩若保存了召唤 LB 落点，可显示估计占位符；同时有召唤物效果和受影响玩家位置时，恢复相应连线。没有保存的信息不会补造。
- 展开回放记录可查看召唤采样、效果数和当前估计占位符数量，便于排查。

回归验证覆盖无主人、无 NPC 样本、仅有 LB 落点、重复技能包、召唤物消失、旧记录恢复、未知落点及地形高度等情况。通过云端自动检查和编译，无法在此环境验证游戏内对象及 GPU 的实际表现。
