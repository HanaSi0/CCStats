# CCStats 0.2.7

- 地图玩家改为小职业图标，保留朝向、队伍色圈、选中与倒地标记。
- 新比赛目标采样提高至 30 Hz，支持真实采样逐帧查看；超长或高密度记录会降低保存密度并提示。
- 水晶显示历史行进轨迹，缺失观测和异常跳变处断线。
- 地图两侧显示双方职业、血量、完整状态图标及悬停倒计时，随回放时间变化。
- 地图计时器触发显示横幅；捕获到的环境 NPC 动作显示来源位置及可跳转事件列表。不推测未知机制的作用范围。

旧记录可读取，但无法补抓完整状态和新增环境动作。各地图机制覆盖、图标布局及实际采样频率需在国际服客户端实测。
