# CCStats 0.2.9

- 新增“3D 回放”按钮，使用独立大窗口、顶部时间轴、双方实时队员面板；玩家使用统一棋子，底部标注职业，水晶使用立体菱形。
- 按需读取本机地图 LGB / SGB / MDL 静态几何，采用纯色光照和深度排序。右键旋转、左键平移、滚轮缩放。
- 新比赛增加玩家和水晶真实 Y 高度，兼容之前两种二进制记录格式。旧记录高度只能作地图表面推定。
- 新增 `/ccstats probe` 和侧栏“地图试验”：无需历史战绩，可查看当前已加载对象、地图资源与投影、XYZ、朝向、体力、状态、读条技能及碰撞半径，并打开当前地图 3D 快照。
- 水晶护送圈准确半径尚未校准。可人工标记圈内／圈外边缘，形成暂定范围；对象碰撞半径单独显示，不能当作护送圈半径。可导出本机试验数据。

这是供国际服实测的试验入口：云环境没有游戏场景资源，尚不能验证具体地图覆盖。缺失模型、达到几何预算或存在尚未接入的 TERA 地形板块时提示几何可能不完整；资源不可读时明确显示坐标网格，不冒充真实地图。此版没有完整材质、动态场景动画及精确深度缓冲。

测试步骤见 [地图试验](../map-probe.md)。

验证：346 项自动检查通过，包括三维投影、模型变换、两种旧记录读取、新高度往返及圈边缘采样；Release / Debug 构建 0 错误。游戏地图资源覆盖仍需国际服客户端实测。
