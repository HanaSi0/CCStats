# CCStats 0.2.14 测试版

设置新增「LB 采集」，用于狼狱停船场的技能研究。与正式比赛记录独立，默认关闭，无自动上传。

1. 进入狼狱停船场，打开 `/ccstats` → 设置 → LB 采集。
2. 点击「开始采集」，释放该职业 LB、全部后续技能，等待持续效果及召唤物消失。
3. 点击「停止并保存」。切换职业后再次开始，每个职业至少一组；切换职业、离开区域和登出会停止当前组。
4. 全部完成后点击「批量导出 ZIP」，打开采集文件夹，将生成的 ZIP 发回分析。

记录本人及本人召唤物的动作效果包、实际目标、动作表范围元数据；采集附近 100 米内最多 64 个已加载战斗对象的位置、高度、朝向、HP/MP、施法和状态。位置目标为 30 次/秒，状态约 10 次/秒，实际频率受游戏帧率影响。每组上限为 10 分钟、约 64 MiB 或 20,000 个动作事件，先达到者停止。数据含角色名字、实体 ID，保存在本机插件配置目录的 lb-captures 下。

不依赖现有 LB ID 列表过滤动作：已知 LB 计数为 0 时仍保存原始动作，便于识别新版本 ID。已有文件不会因导出而删除，导出只包含已结束组的摘要与观测文件。

木人采集可以确认动作链、来源方向、召唤物和部分实际效果，不能单凭一次释放证明范围边界、队友增益或全部地图机制。此版本尚未将全部 LB 范围与地图机制植入 3D 渲染。

已保存官网全部 21 个职业的 PvP 技能与七张地图机制说明，作为后续对照资料。

验证：Release、Debug 构建均 0 错误；404 项检查通过，包含 ZIP 内容、中文数据保真、未完成组排除和导出失败清理。云端没有游戏宿主，实际动作捕获和运行开销待狼狱测试。
