# CCStats 1.0.6

回放地图裁边、出生区恢复与技能范围显示更新。

- 七张 3D 地图按官方二维地图轮廓清理场外部分，围墙及临近边缘保留约 3 个游戏单位余量。
- 从原始导出恢复此前被矩形边界误裁的出生和连接区域，包括九霄云上右上 `(90,-90)`、左下 `(-90,90)` 的出生圆台。
- 保留赤土红沙两侧圆形显示地板，移除低处装饰雾造成的悬空色块；改进地图光照与材质颜色，并补齐机关大殿局部地面。
- LB、地图机制和召唤物地面波纹按可站立显示网格裁剪；根据事件高度选择地面层，减少范围上墙、跨层下拉和竖片。二维机制范围使用相同轮廓。
- 调整动态顶点容量和各类范围预算，增加超限保护；修复已有大范围效果占用过多顶点时，召唤物被旧的全局阈值提前挡掉的问题。
- 移除设置中的“LB 采集”测试页面；正常对局的 LB 记录与回放继续保留。

“裁剪范围”默认开启，可在 3D 回放工具栏关闭。显示网格由模型与官方二维轮廓推导，不是游戏导航或服务器碰撞数据；裁边采用 0.5 单位格，边界存在少量保守余量。

验证：591 项检查、Release/Debug 构建、七张最终模型的浏览器渲染与资源校验通过；原有地面层的邻近同高度覆盖检查通过。尚未完成游戏内 Direct3D 与帧率实测。
