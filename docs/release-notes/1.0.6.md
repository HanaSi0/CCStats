# CCStats 1.0.6

大范围机制与极限技范围改为贴合可站立地面，七张回放地图重新精修。

- 3D 回放中的地图机制和极限技范围不再把顶点抬到墙顶、岩石顶，消除范围圈周边竖起的蓝色/红色碎片。范围按 0.5 单位格裁剪到玩家可站立的地面：遇墙、岩石、峡谷和坑洞自动断开，跨墙的另一条通道仍会显示。桥上与桥下按事件高度选择对应楼层。
- 二维回放的机制范围使用同一可站立网格裁剪。
- 可站立网格再按游戏自带的区域地图（`ui/map/…_m.tex`）裁剪：官方地图上不属于竞技场的区域（例如赤土红沙广场墙外的沙丘）不再显示范围。读取不到地图纹理时保持原网格。
- 七张地图改为平滑光照与 8 位颜色，岩石、沙丘和地面不再呈碎块色斑；墙角、台阶等硬边保留。同平面同材质的多余顶点无损合并。
- 补齐机关大殿庭院中的五处地面空洞。
- 旧记录缺少高度时，优先使用最近的可站立地面，不再落到墙顶。
- 动态图形容量由 12 万提高到 40 万顶点，超出时只截掉末尾范围而不再导致三维视图报错。

可站立网格由显示模型推导，不是游戏碰撞或服务器判定。生成规则见[地图资源说明](../../PvpStats/Resources/ReplayMaps/README.md)。

已用等价的 Python 实现核对裁剪结果，并对七张地图做离线渲染比对。本次修改所在环境没有 .NET SDK，C# 构建和 `tests/LocalizationChecks`（含新增 `ReplayWalkChecks`）需在发布前运行；游戏内 Direct3D 显示仍需实测。
