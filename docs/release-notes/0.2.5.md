# CCStats 0.2.5

- 详情页两队阵容逐行对齐，统一时间、结果与操作按钮；阵容可收起或独立滚动，避免挤压内容。
- 五个详情页独立切换；缺少记录时明确提示，修复空推进曲线访问首元素导致异常的问题。
- 窗口支持边缘缩放和标题栏紧凑／标准／宽屏预设。详情与回放记住关闭时的尺寸，并按屏幕限制大小。
- 新比赛目标走位采样从 2 Hz 提高至 20 Hz。采用独立的紧凑压缩记录，最多 24000 帧；压缩预算不足会降低保存密度并提示。
- 地图默认放大到观测区域，支持缩放、平移、重置和完整地图。同步显示实际观测的战术水晶坐标（金色菱形）；旧记录或坐标缺失时不补造位置。

验证：303 项自动检查通过，包括 20 分钟、10 位玩家、24000 帧的压缩往返测试（约 3 MB）。游戏内窗口、地图、水晶识别和实际采样频率仍需目标客户端实测。
