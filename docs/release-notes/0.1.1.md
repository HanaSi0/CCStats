# CCStats 0.1.1

修复国际服 Dalamud 插件安装器搜索不到 CCStats 的问题。

0.1.0 沿用了官方 PvP Tracker 的内部标识 PvpStats。Dalamud 会拒绝自定义库覆盖官方库中相同 InternalName 的插件，无论原版是否安装。

本版将 InternalName、程序集和清单文件统一为 CCStats，保留 API 15 和全部水晶冲突功能。库链：

```text
https://raw.githubusercontent.com/HanaSi0/CCStats/main/repo.json
```

原有 repo-test.json 链接也同步更新。保存库设置、刷新安装器，在“所有插件”搜索 CCStats。
配置目录改为 CCStats；不会改写或自动读取原版 PvpStats 的配置和数据库。原版与本版注册相同的 /ccstats 指令，游戏测试时请停用原版。

实际采集、Hook 和游戏内界面仍需目标客户端验证。
