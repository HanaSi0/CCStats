# CCStats 1.0.9

新增地图机制占位符和回放图例，精修场景外观与阴阳师动作细节。

- 提供 24 种独特的轻量机制占位符，包含爆弹怪及其魂、羽毛、龙卷、机关、沙坑生物和治疗区等；在三维回放中通过“机制图例”查看。
- 以 5 Hz 记录客户端已加载的机关对象轨迹，合并静止片段并限制记录容量；已有动作和状态记录用于旧战绩的有限回放。
- 阴阳师只显示悬浮眼睛及视线范围：移动时闭眼，按自身实际读条睁眼，结算或中断后闭合，不凭停止移动推断发动。
- 精修爆弹怪面部、火焰、羽片、榻榻米、机关门、机关保镖等外观；实际缩小状态同步缩小玩家棋子。

验证：680 项检查、Release/Debug 构建、24 种样式的浏览器 WebGL 渲染通过。尚未完成游戏内 Direct3D 和帧率实测。

限制：占位符是程序绘制的近似外观，非游戏原生模型。准确冲刺带位置、书库魔力供给读数与桥梁动态状态仍待接入；缺失对象和历史事件不会凭空补全。动态显示取决于对局实际保存的数据。

原有插件库链接继续使用，在卫月检查更新即可。
