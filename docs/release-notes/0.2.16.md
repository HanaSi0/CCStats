- 新比赛补存防御期间控制结果的状态快照，以及自返治疗的来源状态、技能类别，支持辨别暗黑骑士吸血状态和更多职业的明确吸血技能。

控制抵抗可能来自防御以外的免控，因此指标注明「防御期间抵抗」，不将其全部归因为防御。护盾百分比与受击包不足以恢复准确吸收量，不给出虚构吸收总量。治疗和吸血包包含过量治疗，不能当作实际有效回血。只有点击按钮才在本机执行高级计算。
