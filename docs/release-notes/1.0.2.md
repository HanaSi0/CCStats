# CCStats 1.0.2

LB 召唤物在 3D 回放中独立呈现：

- 巴哈姆特与不死鸟使用空中菱形占位符，随实际采集位置显示，消失或数据断档后停止显示。
- 滞留期间以持续扩散波纹显示 30 码自动索敌范围；这是选取目标的距离，不表示对全范围同时造成伤害。
- 攻击效果使用紫色连线，治疗与增益使用薄荷绿连线，与玩家技能的红蓝效果区分。只对效果包中实际受影响的目标绘制，短暂显示后淡出。
- 百万核爆与不死鸟之翼的 15 码范围在观察到实际触发后使用独立扩散波纹。

普通技能继续排除，仅额外采集 LB 召唤物自身的四项关联技能。原有玩家职业单字标记不变。

召唤物对象以每秒 5 次独立采样保存，并受记录容量限制。旧记录没有召唤物对象采样，无法补出完整滞留过程；更新后录制的新对局支持此功能。当前识别元巴哈姆特和元不死鸟的客户端对象，其他非召唤物场地效果保持原有显示。

通过 Release / Debug 编译与自动检查；实际游戏内对象识别和渲染效果仍需实测。
