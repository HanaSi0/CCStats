# CCStats 0.2.10 地图测试版

- `/ccstats probe` → “批量采集进度”，在独立窗口逐张采集地图。进度明确区分读取对象、读取模型、保存和校验，不显示虚假的上传状态。
- 为 Hyperborea 提供目标地图选择；同时记录客户端报告的区域，方便识别静态场景与实际区域不一致的情况。选择不会改变游戏场景。
- 无需加载真实大水晶：站在地图圈中心可设置手动参考中心，或在对象表指定中心，再进行圈边缘测量。3D 菱形明确标为试验参考，不写入正式比赛。
- 每张地图保存独立快照、模型资源路径、实例变换及包围盒、缺失和预算诊断、人工圈边缘样本；只导出派生诊断，不打包游戏模型网格。
- 已完成地图清单可跨重启恢复。最终 ZIP 包含文件哈希清单，只纳入保存并校验成功的地图；错误和中断保留状态，允许重新采集。

数据仅存本机。完成全部地图后将 ZIP 发送到聊天，再分析实际地图数据并更新模型读取与判定圈支持。操作步骤见 [地图试验](../map-probe.md)。

验证：356 项自动检查通过，Release / Debug 构建 0 错误；ZIP 分析工具能读取有效样本并拒绝哈希错误。实际地图资源与圈大小需用户采集后分析。
