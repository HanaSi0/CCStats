# CCStats 0.2.0

- 新增细项与走位记录：采集客户端已加载且属于本局阵容的玩家，包含镜头外对象；每 0.5 秒保存位置、朝向、体力、控制状态，并记录战斗效果及防御受击时双方 Buff 快照、游戏版本和客户端说明。
- 对局详情新增「细项分析与回放」。只有点击「开始细致推算」才在本机后台汇总控制、自返治疗、已识别吸血、承伤和防御条件估算；无法判定的机制显示待核对，不计入估算合计。
- 新增地图二级窗口：播放、拖动时间轴、倍速、角色轨迹、减员与水晶相对推进。地图参数与纹理来自客户端，缺失数据不补造，水晶相对进度不冒充世界坐标。支持导出本局观测 JSON。
- 细项记录存在帧数、事件数与容量限制，达到限制时明确提示；旧战绩不能补抓。性能设置可关闭下一局的细项采集。
- 新记录增加独立采集器标记，避免重启后用上游 2.x 版本规则误判 CCStats 的 0.x 版本，导致时间线隐藏；保留真正旧版上游记录的校验。
- 标题栏菜单、折叠和关闭采用一致图标与间距、明确点击动作，交互窗口关闭鼠标穿透以避免按钮失效。
- 榜单仅保留浏览、搜索、排序和分页，删除原始字段、JSON/CSV 复制和导出工具。当前登录角色按完整姓名及所属世界高亮并支持一键跳转。启动自动检查四个大区一次；手动抓取强制更新当前大区完整缓存，保留 60 秒防重复限制。

规则口径与已知限制见 [细项说明](../detailed-telemetry.md)。自动化测试与构建不代替目标游戏客户端实测；首次进入游戏请完成一场新比赛检查采集、地图纹理和按钮操作。

验证：Release/Debug 构建均为 0 错误，234 项自动检查通过；305 项界面文字扫描未发现未映射英文候选。
