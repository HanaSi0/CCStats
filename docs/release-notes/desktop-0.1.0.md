# CCStats Desktop 0.1.0 · Windows 构建预览

独立 Windows x64 EXE，可与纯净 FF14 同时运行，无需 Dalamud，也无需另装 .NET。现有 Dalamud 插件继续维护，插件库和 1.1.0 版本不变。

- 独立窗口、原 Logo、中文页面、文件拖放、最近记录与本地设置。
- 导入插件导出的回放 JSON，查看地图、玩家全名和观测数量；不修改原文件。
- 分离共用核心，复用分析/回放/七图/榜单代码，为后续完整界面移植准备。
- 新增实验性只读进程采集入口：尝试记录已加载玩家的位置、朝向、血量、职业与状态，流式写盘、后台采样、降低 UI 刷新频率。

**采集布局尚未通过真实游戏验证，可能提示当前客户端未适配。** 当前没有结算、队伍、水晶和动作效果包，不是完整对局采集器；战绩库、榜单页面和 2D/3D 播放界面仍待接入。记录仅标为观测片段，不生成伪造统计。

下载 ZIP 并解压，双击 CCStats.Desktop.exe。设置页可打开数据目录。发布附带 SHA256、Windows 窗口启动检查报告和截图。详见 [桌面开发与范围说明](../desktop.md)。
