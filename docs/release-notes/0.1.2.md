# CCStats 0.1.2

- 首次加载时自动从同级 `PvpStats/data.db` 只读导入水晶冲突战绩、时间线和玩家关联；保留原文件，按记录 ID 合并，已有内容优先。一次事务完成，失败回滚、下次加载重试；完成后不重复导入。旧时间线的程序集类型信息同步适配 CCStats。导入结果见设置 → 界面。
- 修复侧栏切页把子窗口尺寸保存为主窗口尺寸的问题，取消切页、筛选以及详情页标签切换时的自动缩放；可手动调整尺寸。首次更新修复旧版保存的小窗口，默认 1100×740 并适配屏幕。
- 删除赞助按钮和跳转，侧栏所有页面平级排列，去掉分组标题，设置只保留齿轮图标。
- 补齐个人资料的中文文案及无数据提示；胜率标注实际场数。
- 榜单摘要中的“本地榜单”改为“来源”，移除字体不支持的附加符号，悬停查看来源和状态。

原有库链无需修改，刷新安装器并更新 CCStats。若安装了原版 PvP Tracker，请先停用，避免指令冲突及数据库占用。原版的其他模式数据与设置不导入。

Release/Debug 构建与 157 项回归检查通过；实际客户端窗口、采集和真实历史数据库仍需游戏内验证。
