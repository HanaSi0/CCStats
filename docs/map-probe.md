# 地图试验

1. 更新到 0.2.9，登录国际服，进入你可以正常访问的地图。插件不传送角色、不创建副本，也不修改游戏状态。
2. 输入 `/ccstats probe`，或在主窗口侧栏点击“地图试验”。没有历史战绩也能打开。
3. 检查区域和地图 ID、场景资源入口、本人 XYZ。点击“当前地图 3D 试验”打开独立大窗口。右键旋转、左键平移、滚轮缩放。
4. 3D 试验显示采样时刻的快照，重新点击按钮会重新采样并替换快照窗口。它不是现场连续直播。试验不向正式战绩库写入模拟比赛或未知队伍。
5. 进入实际加载战术水晶的地图后，试验页会识别 NameId 11350。显示水晶 XYZ、水平距离、高差及对象碰撞半径。
6. 观察游戏的护送圈，在同一高度的圈内边缘点击“标记此处在圈内”，稍微走出边缘点击“标记此处在圈外”。移动中的水晶会改变采样条件，应暂停在可稳定观测的位置或重复多次交叉核对。
7. 圈内最远距离与圈外最近距离只构成人工标记的参考区间。矛盾的标记不会生成参考半径。更换区域／水晶对象会清空测量，不把碰撞半径当作护送半径。
8. 再打开 3D 试验，暂定参考区间的中点会作为虚线圈半径。没有有效区间时显示可调的默认参考圈；界面明确标注未校准。
9. 点击“导出试验数据”，文件保存在插件配置目录的 `map-probes` 文件夹。含区域／地图元数据、已加载对象原始字段和人工边缘样本；不会上传网络。文件可能包含角色名称，可自行检查后提供。
10. 3D 窗口下方展开“地图事件与减员”旁的“导出观测记录”，会在 `replays` 文件夹保存快照、模型资源路径、成功模型数、缺失数、三角面数、TERA 板块数及预算状态。不会导出模型网格本身。

## 已支持与待验证

- 读取当前客户端的静态背景布局、嵌套共享组和主模型网格，处理实例缩放、旋转和平移；只在点击试验入口后后台加载。
- 为避免卡住游戏，场景最多访问 2000 个实例、128 个唯一模型、6 层共享组、显示 12000 个地图三角面；按已观测活动区域筛选三角面。达到预算会提示不完整。
- 棋子和水晶是真正的三维几何，通过相机投影显示。当前只渲染纯色模型，不包含原版材质、特效、碰撞系统或动态机关动画；深度排序不能保证交叉多边形完全正确遮挡。
- TERA 地形板块当前只探测并报告，不假造其模型命名和坐标关系。部分地图可能主要依赖这些板块，需根据实测资源路径继续补充读取。
- 高度缺失的旧比赛以已加载三角面作表面推定，不能当作真实跳跃轨迹。护送圈也需要实际圈边缘测量，暂定半径不能当作服务端已确认判定。
