# 桌面版与原版功能核对

本轮依据原版 `CrystallineConflictDetailPages`、技能分析表和共享分析代码核对。以下区分界面支持与真实数据完整性，不能将测试夹具通过视为实机数据已完整。

| 功能 | 桌面版现状 | 尚需核实 |
|---|---|---|
| 战绩管理、查询、筛选、收藏、标签、导入导出 | 已实现，保留同一资料库 | 真实完整结算需下方解析条件 |
| 玩家战绩 | 已移除坐标/HP 明细页，使用结算表 | 结算布局缺失时保留空值 |
| 官方结算 | 新增按可见列标题、十人名单、时间窗口核对的解析 | 国际服真实 JSON/诊断快照尚未提供；图标列头、特殊语言布局可能无法识别 |
| 事件时间线 | 按来源分轨，事件标记、缩放、平移、悬停、双击回放 | 内存轮询可能缺少被覆盖的即时事件 |
| 推进图表 | 实际时间横轴、双队百分比阶梯、独立检查点及水晶位置曲线、悬停与跳转 | 旧记录没有推进数据时无法补全 |
| 技能分析 | 来源/类型/名称筛选、使用与命中、伤害/治疗、状态、目标明细 | 原始动作计数缺失时显示空值；轮询效果不能保证完整次数 |
| 技能及场地名称 | 中文名称优先，内置已固定提交的完整英文 Action 名称表；场地机制按类型归并 | 未知或新版本编号需更新名称资料 |
| 队伍 | 使用同一局中唯一确认的队伍修复早期未知归属 | 从未读取到或出现冲突时不推断队伍 |
| 比赛类型 | 新记录读取副本编号，沿用原版的练习、段位、自定赛映射 | 没有保存副本编号的旧文件保持未知 |
| 比赛起止 | 使用开战证据、已保存位置范围和结算出现状态 | 尚未取得原版结果包提供的精确比赛持续时间 |
| 二维/三维回放、LB、召唤物、地图机制 | 保留已移植的共享场景与规则，全球 UTC 时间计算 | 对象和事件本身仍受读取通道覆盖限制 |
| 精确命中状态、减伤、控制抵抗、完整 DoT/HoT | 共享计算器仍在，缺少事件瞬间快照的字段保持不可用 | 原版回调与外部内存轮询的数据能力尚不等同；需额外经过验证的只读事件来源 |

测试包含合成正例及拒绝错误名单、缺列、重复单元格、过期结算等反例。真实结算快照到达后，应先针对该布局增加回归，再扩展识别，禁止根据未标注数字的位置猜测成绩。
