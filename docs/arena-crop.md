# 七图场外裁边与出生区恢复

2026-10-18（日本时间）。在 Claude 交付并检查后的 `5406329` 基础上处理，随 1.0.6 交付。

## 场外处理

七张显示模型按各自官方客户端二维地图的白色竞技场轮廓裁切，只给围墙、掩体和临近边缘保留约 3 游戏单位余量。裁切格距为 0.5；保守格边使实测最远顶点距原白色区域约 3.606 单位。内部不可活动的洞和大型障碍之外也执行相同边界处理，不只是裁一个矩形。

保留切面上的原顶点高度、颜色和透明度插值；原始网格不变的部分直接保留。赤土红沙的装饰性低雾平面删除，避免裁边后出现悬空色块；核心区域的流沙透明效果继续保留。两侧先前补建的圆形显示地板保留。

对于旧矩形边界之外的原生区域，从用户原始 GLB 导出补回，然后统一按官方轮廓裁边，不用临时地板代替原本存在的模型。恢复的数据包括出生圆台、连接区域及薄边内的原生结构。

## 验证

- 使用最终七张 CCM 模型完成浏览器 WebGL2 非空渲染、旋转、重置和俯视检查；赤土红沙两圆心仍有显示地板。
- 14 个模型/地面资源的 SHA256 与 manifest 匹配。
- 对照裁边前全部地面层，在 0.5 单位邻域和 0.65 高度容差内，七图均能找到对应地面层，未发现整片道路或高台丢失。该指标不等于精确碰撞或逐像素面积保真。
- 591 项纯逻辑检查通过，新增九霄云上模型两端范围与两个出生区地面检查。
- Release / Debug 均成功构建，0 错误，保留现有警告。未在游戏内执行 Direct3D 或帧率测试。
