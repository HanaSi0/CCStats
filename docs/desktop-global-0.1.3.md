# 国际服桌面版 0.1.3 内部验证

本轮分三次迭代：旧记录兼容与概览、蓝量和图标侧栏、动效与回归。最终只生成国际服测试包，不发布正式版本。

## 已修复

真实记录中两条技能的 `TargetPlayer` 为 null，事件时间线访问字符串长度导致详情构造失败。现跳过空目标，保留事件；Windows 验证夹具包含相同情况。该真实记录可生成 65 条时间线事件，数据库往返后第 60 秒仍有十人坐标与三维几何。

概览原先只对已结算记录分组，导致三份无结算回放无法出现在地图表。现列出全部记录、比赛、回放及已知胜负；概览搜索独立于战绩页筛选。未结算回放仍不参与胜率计算。

## 回放侧栏

- 复用角色卡片，避免每 0.2 秒重建整个侧栏；状态图标和倒计时只在显示内容变化时更新。
- 状态图标按固定版本 Status.csv 的真实图标编号，从本机游戏 sqpack 只读提取，经 Lumina 解码，在后台线程加载并缓存。无在线图标请求，客户端资源不上传、不修改。
- 首次需要启动游戏完成自动定位，无需开始新对局。之后保留本地路径和按游戏版本区分的图标缓存，游戏关闭时仍可读取安装资源及缓存。
- 没有图标的内部状态不展示为假图标。未收录或缺失资源显示占位并提供提示，不能将占位称为真实图标。
- 显示状态名称提示、剩余秒数和允许叠层的状态层数。
- 蓝量读取经核对的 CharacterData Mana / MaxMana 字段，进行独立范围校验；无效蓝量不影响角色位置。蓝量通过 JSON、压缩数据及位置插值链路保存，旧记录保持“未记录”。
- 压缩数据支持新蓝量格式，同时保留旧格式读取；没有蓝量的旧数据仍使用原有编码。

## 动效

页面使用 220 毫秒五次缓出，辅以最多 90 毫秒的卡片错峰、6–8 像素位移和轻微缩放。保留滚轮缓冲、按钮反馈；不为回放每帧或每次状态刷新添加动效。动画替换前会停止旧时钟，不覆盖已有变换。设置中增加“减少动画”，同时遵循系统动画设置。

## 验证范围

核心测试覆盖 null 目标、旧回放概览、蓝量字段校验、压缩新旧格式、插值保留及状态图标编号。Windows 覆盖界面打开、旧记录详情、概览地图行、蓝量侧栏、角色卡片复用、动画关闭复原、五时区、托盘和回放。

云环境没有真实游戏资源或运行中的国际服客户端，不能将合成窗口检查称为实际图标提取或新版客户端实机读取验证。此前缺失的结算、玩家伤害/治疗及命中瞬间状态不会由本轮修改补造。
