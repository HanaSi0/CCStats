## 采集与生命周期

新增 `DetailedTelemetry.ArenaObjects`：对象完整 64 位 GameObjectId、NameId、BaseId、对象类型、坐标、朝向、原始 EventState、RenderFlags、首次与最后观测时间。国际服客户端英文名称表用于跨界面语言识别，已核对的 NPC 名称 ID 同时做地图限制。

- 每 0.2 秒读取客户端对象表；不要求模型正在镜头里。读写只发生在正常比赛记录中。
- 静止、状态未变化的对象合并时间段，移动或状态变化新增记录。完整对象 ID 避免所有非网络机关的 `0xE0000000` EntityId 相互覆盖。
- 最多 96 个在场对象、16,384 段记录，并计入现有 8 MB 记录预算。未知 EventObj 的 ID、位置与原始状态保留供之后确认，不自动画成某一种机制。
- 回放只使用时间轴当前位置之前的观测，最长保留 0.25 秒采样余量，不用计时器生成拾取物或随机巢穴怪。
- 原始 EventState/RenderFlags 不直接解释成“机关已启用”或“桥已生成”。模型已加载与触发器已启用不是同一概念。
- 新动作可补显示短暂的机制符号；旧记录没有对象轨迹时，不编造羽毛、金币、魂、固定机关的位置和消失时间。
- 爆弹怪与爆弹怪之魂分开识别。自爆结算不会自动生成魂；金币奖励动作 `Well Paid` 也不会在 NPC/玩家脚下制造金币堆。

## 行为规则与自动化边界

用户补充的国服名称与规则进入 `ArenaMechanicGuide`。九霄云上双方未超过 50% 时各一个跳跃台；领先方超过时参考规则为 2/0。对超过一半后相同进度的情况不猜测。该规则目前只用于说明和回归检查，**不凭进度在未知位置自动启用跳跃台**。

书库：供给方离圈或有敌人进圈归零；桥和跳跃台生成后本局持续存在；治疗区减伤 50% 并持续恢复。**客户端供给量、机关启用状态、桥梁端点尚未完成稳定映射**；当前不从未知内存字段、原始 EventState 或普通计时器推定这些信息。桥梁渲染器已经实现，但没有真实端点时只保留机关标记，不画虚构桥面。

固定冲刺带、机关门、流沙、绿洲、金币等已有渲染形状和精确英文标签识别路径；没有已识别对象/有效坐标的对局不会自动补画固定区域。玩家身上的冲刺、羽毛、爆弹魂、绿洲、治疗区状态仅画玩家标记，不能反推固定区域边界或治疗区归属。

以上边界意味着：**24 种样式完成，不等于所有地图动态机关已能完整自动复现**。仍需国际服实测验证对象目录、供给值和桥梁端点/生成状态；不是精确碰撞或游戏原生特效重现。

## 外观精修与阴阳师阶段

爆弹怪增加面部、牙齿、火焰；羽毛改成深色羽片与浅色羽轴；仙人刺使用绿色、面部与纵向纹理，仙人盾另有盾形；机关榻榻米使用草席色、深色包边与细纹，机关门使用木框与金色檐边；机关保镖增加斗笠、护甲、四肢和刀；球体增加面向光源的明暗。风卷增加轻薄带状面，金币、水柱、恢复区、魔力检测点与光桥也补细节。这些仍是程序化轻量近似，不是已提取、核实的原生 NPC 模型或特效。

阴阳师记录独立 EntityId。眼睛只跟随该 NPC 的 `32366` 读条/结算：约 0.2 秒平滑睁开，实际施法期间保持睁开，结算后短暂强调再闭合；读条中断则依最后观测时间闭合。由过去位置确认仍在移动时保持闭眼；静止本身不会启动视线攻击。回拖时间轴时重新由记录计算，不依赖已播放过的状态。图例专门用 4 秒示意循环展示开合，实际对局不使用这个循环计时。

[眼睛阶段图](previews/map-mechanics/Onmyoji-phases.png) · [开合动图](previews/map-mechanics/Onmyoji-cycle.gif)。图例导出用 32 个眼睛阶段采样，其余样式 8 个采样。精修后增加机关模型的独立顶点预算，避免多个爆弹怪因为模型更细致而被旧的 24,000 顶点阈值提前截断；全局 GPU 上限继续保留。

## 加速带定位检查

已检查用户提供的七张原始 GLB：未找到 VFX 网格批次，也未找到名称含 VFX、trigger、sprint、speed 或 avfx 的节点；详细资源清点见 [记录](research/sprint-zone-resource-inventory.json)。这不表示原游戏没有这些机制，只表示目前导出没有可直接认定为加速带的节点。通用 gmc 资源名和官方二维轮廓都不足以确定完整边界，不根据玩家获得极速冲刺的位置伪造一整条加速带。

渲染器已有专用流动箭头样式，并允许七图中实际被识别的冲刺带对象/状态显示；**尚未提取七图的准确静态加速带坐标或范围，未将任意道路自动标为加速带**。后续需要原始客户端 LGB/SGB/VFX 资源或可核对的场景放置数据。官方指南截图已从缓存网页定位到 `lds-img.finalfantasyxiv.com`，该图片主机也已加入网络配置草稿，生效前仍无法下载核对外观和位置。
