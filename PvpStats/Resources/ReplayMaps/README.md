# 回放地图资源

七张地图来自用户提供的 Meddle 导出，离线精简后单独保存。保留主要地面、掩体和高差，清除无关外景、遮挡复盘的屋顶和细小装饰；峡谷的可见岩壁与场地之间的原生地面保留；显示模型不作为游戏碰撞或导航网格。

每张地图有两个资源，均嵌入程序集，仅在打开对应回放时解压：

- `<地图>.ccmap.gz`：显示模型。解压后按 little endian 存储：4 字节 `CCM4`、int32 顶点数、int32 索引数、每顶点 3 个 float32 世界坐标及 RGBA8，最后为 uint32 三角形索引。海岸斗场、休兵书库保留原世界坐标偏移。
- `<地图>.ccwalk.gz`：可站立地面网格，供技能范围、地图机制贴地和旧记录缺失高度使用。解压后为 `CCW1`、int32 宽、int32 深、float32 原点 X/Z、float32 格距（0.5），随后每格 1 字节层数，最后按格顺序存放 float32 地面高度（同格由低到高）。

解析器限制顶点/索引/层数、坐标与索引范围，拒绝尾部多余数据。

## 1.0.6 精修

`tools/refine_replay_maps.py` 以 1.0.5 资源为输入：

- 焊接重合顶点，删除退化面和重复面。
- 1.0.5 每面颜色为「材质色 × 面光照」再量化到 4 位。按相邻面颜色区间求交还原材质色，再以 40° 折角平滑法线重新计算光照，输出 8 位颜色。岩石和沙丘不再呈碎块状色斑，墙角、台阶等硬边保持。
- 同一材质、同一平面内的扇形内部顶点做无损折叠，轮廓与颜色不变。
- 机关大殿庭院中五处被移除装饰后留下的空洞（四周为同一高度地面）按周边高度和颜色补齐。仅为显示补建。

可站立网格由 `tools/replay_walkable.py` 生成：把不透明三角形采样为 0.5 单位格的竖向区间；顶面坡度不超过约 35°、上方净空至少 1.8 单位的为地面；从场地中心出发，相邻格高差不超过 0.6 单位连通的地面保留。墙顶、岩石顶、峡谷底和屋顶因此排除。海岸斗场额外从沙地出发。显示模型可能经墙体缺口把场外地面连进来，因此回放时再用游戏区域地图纹理的竞技场轮廓（浅色区域）裁剪一次（`ReplayMapSilhouette`）。离线核对：角力学校、火山之心、九霄云上的官方地图与网格对齐（4 像素/单位），轮廓外分别剔除 9.0%、1.7%、13.6% 的格。该网格不等于游戏碰撞或服务器判定。

`manifest.json` 记录面数、顶点数、两个资源的大小与 SHA-256、可站立格数和补洞位置。

离线工具：`tools/rebuild_replay_maps.py`（从用户导出的 GLB 恢复核心地形）、`tools/restore_core_surfaces.py`、`tools/optimize_replay_maps.py`（1.0.5 及以前的打包）、`tools/refine_replay_maps.py`（1.0.6 精修与可站立网格）；依赖在 `tools/requirements-map-build.txt`。原始地图导出不包含在仓库中。
