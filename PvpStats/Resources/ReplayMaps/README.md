# 回放地图资源

七张地图来自用户提供的 Meddle 导出，离线精简后单独保存，范围为竞技场及紧邻的周边景物。显示模型不是游戏碰撞或导航网格。

每张地图两个嵌入资源，仅在打开对应回放时解压：

- `<地图>.ccmap.gz`：显示模型。little endian：`CCM4`、int32 顶点数、int32 索引数、每顶点 3×float32 世界坐标 + RGBA8，最后 uint32 三角形索引。海岸斗场、休兵书库保留原世界坐标偏移。
- `<地图>.ccwalk.gz`：可站立地面网格，供技能/机制/召唤物范围裁剪（`ReplayArenaMask.FromWalk`）和旧记录缺失高度使用。`CCW1`、int32 宽、int32 深、float32 原点 X/Z、float32 格距（0.5），每格 1 字节层数，随后按格顺序 float32 地面高度（同格由低到高）。

## 待发布精修（候选 1.0.6）（`tools/refine_replay_maps.py`，输入为 1.0.5 资源）

- 地图范围与 1.0.5 相同（保留紧挨竞技场的景物）；只提高显示精度：焊接顶点、删退化/重复面；由 1.0.5 的 4 位逐面颜色还原材质色，再按 40° 折角平滑法线重新打光，输出 8 位颜色；同材质共面扇形无损合并；补齐机关大殿庭院五处地面空洞。
- 可站立网格（`tools/replay_walkable.py`）：不透明三角形采样为 0.5 单位格竖向区间；顶面坡度 ≤ 约 35°、上方净空 ≥ 1.8 的为地面。只保留落在游戏区域地图竞技场轮廓内的地面（`docs/exports/official-maps-2d/images/<地图>.png`，即 `ui/map/s5pN/00/s5pN00_m.tex`；缩放 400 = 4 像素/单位，海岸斗场与休兵书库偏移 −100），补齐 1–2 格木板缝，去掉少于 64 格的碎块（拱门顶等）。跳板平台也计入。
- 一格可有多层地面（桥上/桥下、平台/下方沙地）。范围贴离事件高度最近的一层；与事件高度相差超过 4 单位的层不画（`ReplayArenaMask.MaxLayerDrop`）。

已知限制：九霄云上两端出生区在 1.0.4 重建时已不在模型内（模型 z 约 −57～46，官方地图 ±96），该处没有地面也不显示范围；需原始 GLB 才能补回。地面装饰物底部可能留有零星小空洞。这些都只影响复盘显示。

`manifest.json` 记录面数、顶点数、两个资源大小与 SHA-256、可站立格数、补洞位置。
