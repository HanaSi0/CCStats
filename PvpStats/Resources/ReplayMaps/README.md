# 回放地图资源

七张地图来自用户提供的 Meddle 导出，离线精简后单独保存。保留主要地面、掩体和高差，清除无关外景、遮挡复盘的屋顶和细小装饰；峡谷的可见岩壁与场地之间的原生地面保留；显示模型不作为游戏碰撞或导航网格。颜色为原材质的平均色，不依赖外部贴图。

`manifest.json` 记录面数与资源 SHA-256。每个 `.ccmap.gz` 解压后按 little endian 存储：4 字节 `CCM4`、int32 顶点数、int32 索引数、每顶点 3 个 float32 世界坐标及 RGBA8，最后为 uint32 三角形索引。海岸斗场、休兵书库已恢复原世界坐标偏移；不使用预览居中的坐标。

资源嵌入程序集，仅在打开对应 3D 回放时解压。解析器限制顶点/索引数量、坐标与索引范围；旧记录缺失的 Y 通过显示地形估计，不能作为原始观测值。

1.0.4 复查七张地图：赤土红沙不再按可行走地面包络和 −8～9 高度范围裁剪，恢复原始峡谷岩壁、坡面与连接结构；海岸斗场保留原有精简平台，仅补入原生地面及完整场地标识，不恢复远景建筑和散落装饰。其余五张保留核心布局，仅执行重复几何清理、受面积/边界约束的无损简化和显示颜色合并。

[资源复查记录](../../../docs/research/map-core-audit.json) 包含逐图哈希、面数、顶点数和最终优化前后的地面投影覆盖检查。该检查不等于游戏内可达性或碰撞验证。

离线构建工具：`tools/rebuild_replay_maps.py`（从用户导出的 GLB 恢复核心地形）、`tools/restore_core_surfaces.py`（按资源名称仅恢复需要的原生表面）、`tools/optimize_replay_maps.py`（网格清理与 CCM 打包）；依赖在 `tools/requirements-map-build.txt`。原始地图导出不包含在仓库中。
