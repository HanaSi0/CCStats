# 回放地图资源

七张地图来自用户提供的 Meddle 导出，离线精简后单独保存。保留主要地面、掩体和高差，清除外景、屋顶、地下支撑与装饰；显示模型不作为游戏碰撞或导航网格。颜色为原材质的平均色，不依赖外部贴图。

`manifest.json` 记录面数与资源 SHA-256。每个 `.ccmap.gz` 解压后按 little endian 存储：4 字节 `CCM4`、int32 顶点数、int32 索引数、每顶点 3 个 float32 世界坐标及 RGBA8，最后为 uint32 三角形索引。海岸斗场、休兵书库已恢复原世界坐标偏移；不使用预览居中的坐标。

资源嵌入程序集，仅在打开对应 3D 回放时解压。解析器限制顶点/索引数量、坐标与索引范围；旧记录缺失的 Y 通过显示地形估计，不能作为原始观测值。
