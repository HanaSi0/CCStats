CCstats 国服测试版
作者：HanaSi0

解压全部文件，运行 CCStats.Desktop.exe，无需额外安装 .NET。
自动识别游戏进程和游戏窗口，关闭窗口时可选择最小化到托盘继续后台记录。

此构建移除了排行榜页面与联网服务。其余战绩管理、分析和回放功能沿用当前桌面版。
数据独立保存在 %LocalAppData%\CCStatsDesktop-CN，国际版的数据目录保持独立。
可通过读取文件导入现有 JSON 或历史数据库。

国服客户端版本的实际内存读取尚需实机验证。签名不匹配时会停止连接，不会猜测地址。
缺失的官方结算和瞬时战斗数据无法由位置记录补全。
遇到读取问题，请在设置中使用“导出诊断”，并保留对应对局的 JSON。
