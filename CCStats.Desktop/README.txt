CCStats Desktop · Windows 水晶冲突工作台

解压后运行 CCStats.Desktop.exe。软件自动识别游戏进程，支持在托盘中后台运行。

关闭主窗口时可选择“立即退出”或“最小化到托盘”，并勾选“记住我的选择”；设置页可以随时修改。最小化不停止采样和写盘。右下角托盘图标可以恢复窗口或退出。

战绩查询、筛选、收藏、标签、结算详情、职业/玩家分析、个人纪录、段位趋势、官方榜单、时间线、技能分析、按需高级推算和地图回放使用已保存的真实数据。可读取已有 JSON 和历史数据库。

数据保存：%LOCALAPPDATA%\CCStatsDesktop。原始数据文件保持不变。

独立采集的客户端布局仍需在真实游戏中确认；尚未读到的结算、队伍、水晶和技能事件不会补造，观测片段不会伪装为完整比赛。软件能显示已有记录中的完整字段，不代表当前采集器已经能获取所有字段。
